## 💡 **USAGE GUIDE**

### **1. Login**
```
1. Open application
2. Select user account from login page
3. System loads role & permissions
4. Navigation filters based on role
```

### **2. Navigate**
```
1. Sidebar shows only allowed pages
2. Click any page to access it
3. Use Quick Actions (FAB) for fast operations
4. Press Ctrl+K for global search
```

### **3. Work Efficiently**
```
1. Use keyboard shortcuts (Ctrl+N, Ctrl+K, Ctrl+D)
2. Export data regularly (JSON/CSV)
3. Check notifications for pending tasks
4. Monitor reports for insights
```

### **4. Logout**
```
1. Click logout button in header
2. Session is cleared
3. Return to login page
```
